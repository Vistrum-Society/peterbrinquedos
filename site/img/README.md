# Fotos dos produtos

Suba aqui as fotos dos produtos (fundo branco), **nomeadas pelo código do produto**:

- `1060.jpg` · `2210.jpg` · `3120.jpg` ...

O site casa a foto com o produto automaticamente pelo código (SKU). Use `.jpg` ou `.png`, fundo branco, de preferência quadradas (1000x1000). Se faltar a foto de algum produto, aparece um emoji de reserva no lugar (nunca quebra).
