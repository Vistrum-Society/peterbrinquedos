Publicar a página no domínio da Peter (Vercel)

O Vercel hospeda a página de graça; o registro.br só aponta o domínio para ele. São 6 passos. Faça na ordem.

Antes de começar

Como funciona

A página (o arquivo index.html) já está no repositório, na pasta site/. Falta subir as 2 imagens que ela usa, conectar o Vercel e apontar o domínio. Você precisa estar logado no GitHub (conta da Vistrum), no Vercel e no registro.br.

Passo a passo

Publicando

1

Subir as 2 imagens pro GitHub

A página usa logo-peter.png e fundo.png. Elas precisam ficar dentro da pasta site/.

  1. Abra o repositório no GitHub e entre na pasta site/.
  2. Clique em Add file → Upload files.
  3. Arraste logo-peter.png e fundo.png (as mesmas da sua pasta Peter).
  4. Clique em Commit changes. Confira: a pasta site/ deve ter index.html, logo-peter.png e fundo.png.
2

Conectar o Vercel ao repositório

  1. Entre em vercel.com e faça login (pode ser com a conta do GitHub).
  2. Add New… → Project.
  3. Em Import Git Repository, escolha Vistrum-Society/peterbrinquedos. Se não aparecer, clique em Adjust GitHub App Permissions e libere o acesso a esse repositório.
3

Configurar e publicar

  • Root Directory: clique em Edit e selecione a pasta site. (Passo mais importante.)
  • Framework Preset: Other.
  • Branch: se pedir, use claude/peter-brinquedos-briefing-m192it por enquanto.
  • Clique em Deploy e aguarde. No fim, o Vercel te dá um endereço algo.vercel.app.
✅ Abra o .vercel.app e confira: logo, fundo e botões devem aparecer certinho. Se a imagem não carregar, revise o Passo 1 (nome/pasta das imagens).
4

Adicionar o domínio da Peter no Vercel

  1. No projeto: Settings → Domains.
  2. Digite o domínio da Peter (ex.: peterbrinquedos.com.br) e clique em Add.
  3. O Vercel vai mostrar os registros DNS que você precisa criar. Anote exatamente o que ele mostrar (os valores abaixo são o padrão).
5

Apontar o DNS no registro.br

No registro.br, entre no domínio e vá em Editar Zona DNS (DNS do registro.br). Crie os registros que o Vercel pediu. Normalmente:

TipoNome / HostValor
A@ (domínio raiz)76.76.21.21
CNAMEwwwcname.vercel-dns.com
Use o que o Vercel mostrar na SUA tela (o IP do registro A pode variar). Se o registro.br não aceitar CNAME no raiz, use o registro A no raiz e o CNAME só no www, como na tabela.
6

Aguardar e finalizar

  • A propagação do DNS leva de alguns minutos a algumas horas. No Vercel, o domínio fica Valid quando reconhecer.
  • O Vercel emite o HTTPS (cadeado) automaticamente.
  • Quando abrir no domínio da Peter, atualize o link na bio do Instagram para esse endereço.
Depois (melhorias combinadas na reunião)

Próxima versão da página
