# Como colocar as imagens reais (logo + criativos)

Os arquivos HTML (manual de marca e página de conversão) já estão prontos e apontam para as suas imagens reais. Falta só um passo: **salvar as imagens na mesma pasta dos arquivos HTML, com os nomes exatos abaixo.** Assim, ao abrir o HTML no navegador, sua logo e seus criativos aparecem no lugar (nada fica em branco).

## Por que esse passo é manual

O ambiente onde eu trabalho bloqueia o download das suas imagens do Drive (elas têm mais de 1 MB cada), e as imagens que você cola no chat não chegam até mim como arquivo. Então eu não consigo embutir os bytes dentro do HTML publicado. A solução robusta: o HTML referencia os arquivos pelo nome, e você (que já tem os arquivos) os coloca na pasta. Ao abrir localmente, tudo aparece.

## Nomes exatos dos arquivos

Salve na mesma pasta de `21-manual-identidade-visual.html` e `13-pagina-conversao.html`:

| Nome do arquivo | O que é |
|---|---|
| `logo-peter.png` | A logo oficial (selo com ursinho + trem + PETER) |
| `fundo.jpg` | Foto de fundo da página de conversão (criança + blocos) |
| `post-caminhao.jpg` | Criativo azul "Diversão que constrói" (caminhão) |
| `post-boneca.jpg` | Criativo azul "Feito pra cada fase" (bebê frutinhas) |
| `post-panelinha.jpg` | Criativo amarelo "Cada brincadeira ensina" (cozinha/chef) |
| `post-ferramentas.jpg` | Criativo laranja "Imaginação em ação" (capacete + ferramentas) |
| `post-carrinho.jpg` | Criativo vermelho "Hoje ela vira gente grande" (carrinho de mercado) |
| `post-carriola.jpg` | Criativo amarelo "Diversão que desenvolve" (carriola) |
| `produto-exemplo.jpg` | (opcional) Foto de um produto pro exemplo de catálogo |

Obs.: se o nome do seu arquivo tiver `.png` em vez de `.jpg`, é só renomear (ou me avisar que eu troco a extensão no HTML).

## Como abrir e exportar

1. Coloque os arquivos com os nomes acima na pasta.
2. Dê dois cliques no HTML (abre no navegador) — a logo e os criativos aparecem.
3. Para virar PDF: no navegador, `Ctrl/Cmd + P` → "Salvar como PDF" (margens: nenhuma).
4. Para print de uma seção: use o próprio navegador ou a ferramenta de captura.

Se faltar algum arquivo, aquele espaço mostra automaticamente um mockup de reserva (nunca uma imagem quebrada).
